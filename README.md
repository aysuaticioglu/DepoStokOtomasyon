# Depo ve Stok Otomasyon Sistemi

C# ve .NET Framework kullanılarak geliştirilen, depo yönetimi, stok takibi, depo transferleri ve cari hesap işlemlerini tek bir masaüstü uygulamasında birleştiren otomasyon projesi.

## Proje Hakkında

Bu proje, eğitimim sırasında bireysel olarak geliştirdiğim bir masaüstü yazılım uygulamasıdır.

Temel amacı depo ve stok yönetimi süreçlerinin dijital ortamda takip edilmesini, kayıt altına alınmasını ve raporlanmasını sağlamaktır.

## Özellikler

- Kullanıcı girişi ve oturum yönetimi
- Stok tanımlama ve stok listeleme
- Stok giriş ve çıkış işlemleri
- Mevcut stok takibi
- Depo tanımlama ve depo sayımı
- Depolar arası stok transferi
- Firma ve cari hesap yönetimi
- Kasa ve hesap hareketleri
- Depo transfer analizleri
- PDF formatında raporlama

## Kullanılan Teknolojiler

- C#
- .NET Framework 4.7.2
- Windows Forms
- Microsoft SQL Server
- ADO.NET
- Bunifu UI
- DevExpress
- LiveCharts
- iTextSharp

## Mimari ve Teknik Yaklaşım

- Windows Forms tabanlı masaüstü uygulama geliştirme
- SQL Server ile veritabanı entegrasyonu
- ADO.NET kullanılarak veri erişimi
- SQL sorguları ile veri listeleme, filtreleme ve ilişkilendirme
- PDF raporlama ve veri görselleştirme

## Geliştirici

Bireysel proje olarak geliştirilmiştir.
